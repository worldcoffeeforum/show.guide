# 월드커피포럼 2026 모바일 쇼가이드 (테스트)

`worldcoffeeforum/show.guide`를 복사해서 미니멀 디자인을 적용하고, 「세션 플래너」 조회·수정 기능을 붙인 테스트 버전이다.

## 구성
| 경로 | 내용 |
|---|---|
| `index.html`, `en/index.html` | 쇼가이드 (국문에만 「세션 플래너」 섹션 `#my`) |
| `css/style.css` | 미니멀 테마 + 내 신청 화면 스타일 |
| `js/config.js` | **API_URL** 설정 (비우면 테스트 모드) |
| `js/planner.js` | 조회 · 결과 · 수정 화면 |
| `apps-script/Code.gs`, `appsscript.json` | 통합관리시트에 붙이는 Apps Script 웹앱 |

## 세션 플래너 공개 스위치 (2026-11-10)
- `js/nav.js` 맨 위 `PLANNER_OPEN` 값으로 켜고 끈다. `false`면 메뉴의 「세션 플래너 로그인」, 오른쪽 아래 바로가기 버튼이 사라지고 `planner.html`은 "준비 중" 안내만 보인다.
- 비공개 상태에서도 주소 끝에 `?planner=test`를 붙여 한 번 열면 그 브라우저에서만 계속 보인다 (예: `https://worldcoffeeforum.github.io/show.guide/?planner=test`). `?planner=off`로 해제.
- 공개할 때는 `PLANNER_OPEN = true`로 바꾸고, html의 `?v=` 값을 올려 캐시를 갱신한다.

## 세션 플래너
- 로그인: 이름 + 휴대전화 (해외 번호는 이메일). 로그인 전에는 수요조사 관련 문구를 보여 주지 않는다.
- 본인 확인 출처: `티켓 명단` 탭(유료 구매자, **권종** 포함, 첫 로그인 때 자동 생성) → `초청 MB 명단` 탭 → 수요조사 응답자(모두 MB 소지자)
- MB 패스(유료·초청): All About Q를 뺀 전 세션 참관 가능. 수요조사 응답 조회·수정·신규 응답
- 단권: `권종 관리` 탭에서 1 표시된 세션만 참관 가능. 수요조사 없음
- 세션 상세: 참관 가능 초록 / 불가 회색, 혼잡도 초록(여유)·주황(보통)·빨강(혼잡). 혼잡도는 `세션 현황` 상태 기반이며 실시간이 아님

## 테스트 모드
`API_URL`이 비어 있거나 주소 뒤에 `?mock=1`을 붙이면 예시 데이터로 동작한다.
- 김커피 010-1234-5678: MB 구매자, 수요조사 응답함
- 최구매 010-4444-5555: MB 구매자, 미응답
- 박엠비 010-3333-4444: MB 초청자(티켓에 「(초청)」 표시), 미응답
- 이단권 010-2222-3333: The Sessions 목요일권 + Champion Live

## 실제 연결
1. 통합관리시트 → 확장 프로그램 → Apps Script
2. `Code.gs` 붙여 넣기, 프로젝트 설정 시간대 `Asia/Seoul`
3. 편집기에서 `testLogin` 실행 → 권한 허용 → 로그 확인
4. 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자) → URL을 `js/config.js`의 `API_URL`에 넣기
5. `티켓 명단` 탭에 예약자 정보(채널·권종·이름·휴대전화·이메일)를 채운다. 권종 이름은 `권종 관리` A열과 같아야 한다.

## 데이터 흐름
- 수요조사 저장: `수정 응답` 탭에 한 줄 추가(원본·통합 탭은 건드리지 않음). 세션 현황 집계에 넣으려면 통합 탭 수식에 이 탭을 블록으로 추가해야 한다(미적용).
